# VibeHost — UI demo

**→ [chaotic97.github.io/vibehost-demo](https://chaotic97.github.io/vibehost-demo/)**

A static preview of the VibeHost dashboard, published so it can be looked at
without running anything.

**Everything in it is fake.** There's no backend attached — the app list, the
statuses, the crash report and the spend figures are all in-memory demo data
generated in the browser. Deploying a zip won't upload it anywhere; the build
you'll see "run" is a timer. That's the point: it's a mockup of the interface,
not a working service.

This repository contains only compiled front-end assets. The application
itself lives elsewhere and is not open source.
